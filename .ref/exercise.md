# ATM Application Coding Exercise

Overview — Design and implement a web-based ATM application that lets a user manage two bank accounts. The goal is to showcase your software design and architecture within a focused scope.

## Requirements
- A web-based ATM interface supporting: deposit funds, withdraw funds, and transfer between the two accounts
- Track account balances and transaction history
- Single-user (no authentication required)

## Technical guidelines
- Backend: .NET/C#
- Frontend: any technology you’re comfortable with. UX/design isn’t a primary scoring criterion, but good design is still good design — no need to over-invest (this isn’t a design role), just don’t disregard it entirely.
- Database: in-memory or persistent — your call
- AI: perfectly acceptable, but you must understand and be able to discuss the code you submit, the tradeoffs involved, and your overall approach and strategy
- Evaluation criteria — code organization & architecture, separation of concerns, error handling, code quality/readability, and technical choices & tradeoffs.
